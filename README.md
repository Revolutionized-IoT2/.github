# .github

Organization-level files for [Revolutionized-IoT2](https://github.com/Revolutionized-IoT2), and
the platform documentation hub.

- [docs/README.md](docs/README.md): the platform documentation index. It covers architecture,
  contracts (MQTT, HTTP/gRPC, environment variables, configuration) and architecture decision
  records.
- [AGENTS.md](AGENTS.md): the workspace guide for AI coding agents. It has a repository map,
  build/test commands and platform-wide rules.
- [profile/README.md](profile/README.md): the organization profile. It has the platform overview,
  component map, getting started, security considerations and upgrade notes.
- [PLATFORM-REVIEW.md](PLATFORM-REVIEW.md): the latest cross-repository review. It has fixes, the
  open issues backlog, maintainability implementation plans, architecture proposals, feature ideas
  and the roadmap.
